    HOW TO PLAY

    Walk. Stop. Learn. Shoot.

    Two developers walk the same road through six tiers. At every gate a problem card — real bad code — slams into both of them. Player 1 is a vibe coder with no tools: every hit sticks. Player 2 plays a tool card that fixes the code and heals to 100%. At the end of each tier, the boss is made of the tier's problems; only the tools can break it.
